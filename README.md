# 群消息秘书 (QQ Secretary)

QQ 群通知归类总结工具。自动采集指定 QQ 群的消息，交给 AI 整理成结构化日报，按截止日期从近到远排序，支持把重要通知加入待办清单跟踪。

面向「需要从多个 QQ 群中快速筛选重要通知」的场景：比如项目群里的部署通知、截止提醒、需要处理的文件等。

## 功能特性

- **自动采集** — 通过 NapCat（OneBot 11 协议）连接 QQ，实时采集指定群消息
- **AI 整理成条目** — LLM 提取每条通知的「核心标题」+「截止日期」，保留原通知原文
- **智能合并** — 多条相关消息（如同一人连续发的文字 + 多个文件）自动合并为一条通知
- **按截止日期排序** — 从近到远，无截止日期的排在最后
- **文件关联** — 通知附带文件自动下载到本地，可在日报中直接打开/定位
- **我的待办** — 把重要通知加入待办，可编辑截止日期，手动勾选完成
- **待办提醒** — 临近截止时弹系统通知，避免遗漏
- **当天截止即时日报** — 本地关键词识别（"今天/当天/日期"），命中则立即整理一份日报
- **日报搜索 / 导出** — 按关键词/群号/日期筛选，支持复制内容、导出 Markdown
- **群名显示** — 自动获取群名称（而非仅显示群号）
- **多套 LLM 配置** — 保存多套 API 配置随时切换
- **数据管理** — 可配置保留天数自动清理旧数据

## 架构

```
┌─────────────────────────────────────────────┐
│  PC 本机                                      │
│                                              │
│  ┌──────────┐   OneBot 11    ┌────────────┐  │
│  │ NapCat   │◀─WebSocket───│ 群消息秘书  │  │
│  │ (QQ机器人)│   localhost   │ (Electron) │  │
│  └──────────┘               │            │  │
│        │                    │ • 消息存储  │  │
│        │                    │ • AI 整理   │  │
│        │                    │ • 日报生成  │  │
│        │                    │ • 待办管理  │  │
│        │                    └──────┬─────┘  │
│        │                           │        │
└────────┼───────────────────────────┼────────┘
         │                           │
      登录 QQ                  调用用户自备的
                              LLM API (OpenAI 兼容)
```

- **消息源**：NapCat（本机运行，localhost 直连，稳定无保活问题）
- **应用**：Electron + Vite + Vue 3 + TypeScript，纯本地应用，无远程后端
- **AI**：调用用户自己提供的 OpenAI 兼容 API（密钥只在本地使用）

## 快速开始

### 方式一：下载即用（推荐）

1. 到 [Releases](../../releases) 下载 `Secretary-v1.0.0.zip`
2. 解压后双击 `启动.bat`（会自动请求管理员权限）
3. 在弹出的 NapCat 窗口扫码登录 QQ
4. 在应用的「设置」里填写 LLM API Key 和要监控的群号
5. 完成

> 压缩包已内置 NapCat，无需另外下载。详细步骤见包内 `使用说明.txt`。

### 方式二：从源码运行

```bash
# 需要 Node.js 18+
npm install
npm run dev      # 开发模式
npm run build    # 构建
npm run preview  # 运行构建产物
```

需要另外安装并运行 [NapCatQQ](https://github.com/NapNeko/NapCatQQ)，在其 WebUI 中配置一个正向 WebSocket 服务器（`127.0.0.1:3001`）。

## 配置说明

在应用「设置」页配置：

| 项 | 说明 |
|---|---|
| OneBot 地址 | `ws://127.0.0.1:3001` |
| LLM API 地址 | 如 `https://api.deepseek.com/v1`（自动补全 `/chat/completions`） |
| API Key | 你的密钥 |
| 模型名称 | 如 `deepseek-chat` |
| 用户角色 | 如「我是后端开发，关注部署和 bug」，AI 据此判断相关性 |
| 目标群号 | 逗号分隔；留空则采集所有群 |
| 日报时间 | 如 `22:00` |

点「测试连接」可验证 LLM API 是否可用。

## 常见问题

**Q: 显示"未连接"采集不到消息？**
确认 NapCat 已登录 QQ、配置的是「WebSocket 服务器」且端口为 3001。

**Q: 日报像是没经过 AI 整理？**
多半是 LLM API 调用失败走了降级逻辑，在「设置」点「测试连接」检查。

**Q: 群名显示为数字？**
群名需通过 NapCat API 获取，收到该群消息后会自动缓存。
